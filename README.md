# 丈量APP — 藍牙測距量房平台

參考「樂規劃」與「量房神器」的現場量房流程，做成**純網頁平台**：
用瀏覽器直接連上 Kcsoft（科創）、MILESEEY（迈測）等藍牙雷射測距儀，
邊量邊畫平面圖，自動算面積、出 CAD 圖與 3D 模型，全程離線可用。

---

## 快速開始

**雙擊 `啟動丈量APP.bat`** — 會自動開伺服器並打開瀏覽器。關掉那個黑視窗就停止。

或手動：

```bash
node server.mjs 5173 --open
```

不需要 `npm install`，零相依套件。

> ### ⚠ 不要直接雙擊 `index.html`
> 用 `file://` 開啟時，Chrome 會封鎖 ES 模組（CORS）、Web Bluetooth 與 Service Worker，
> 畫面會是黑的、按鈕全都沒反應。**這不是程式壞掉，是開啟方式的問題。**
> 程式已內建防呆，偵測到 `file://` 會直接顯示提示。

---

## 部署

`node build.mjs` 會產生 `dist/` 與 `dist.zip`（約 120 KB、27 個檔案），
可直接上傳到任何靜態託管（Cloudflare Pages / Workers、Netlify、GitHub Pages）。

上傳到**既有專案**即可沿用原網址；開新專案才會換網址。

靜態託管沒有 `/api`，所以「雲端同步」與「分享連結」不會運作 —— 程式偵測得到並會明講。
量房、繪圖、面積、DXF／DAE 匯出、藍牙測距全部照常。

## 手機上線（現場量房用）

Web Bluetooth 只在 **https://** 或 **http://localhost** 下可用，
所以手機連本機 IP 的 http 是不行的。

| 做法 | 說明 |
|---|---|
| **自簽 HTTPS** | Git Bash 執行下面指令產生憑證，再跑 `node server.mjs --https`，手機開 `https://<電腦IP>:5443` 並手動信任 |
| **USB 埠轉發**（最穩） | 手機 USB 接電腦，執行 `adb reverse tcp:5173 tcp:5173`，手機開 `http://localhost:5173` — 算 localhost |
| **部署到正式網域** | 任何支援 HTTPS 的靜態主機皆可 |

```bash
openssl req -x509 -newkey rsa:2048 -nodes -keyout key.pem -out cert.pem -days 365 -subj "/CN=localhost"
```

### 瀏覽器支援

| 平台 | 藍牙測距儀 |
|---|---|
| Android Chrome / Edge | ✅ 原生支援 |
| Windows / macOS Chrome / Edge | ✅ 原生支援 |
| **iPhone / iPad 的 Safari、Chrome、Edge、Firefox** | ❌ **全部不行** |
| iPhone / iPad + **Bluefy** | ✅ |

> **iOS 上換瀏覽器沒有用。** Apple 規定 iOS 上所有瀏覽器都必須使用 WebKit 引擎，
> 所以 iOS 版的 Chrome、Edge、Firefox 底層都是 Safari —— 而 Safari 至今沒有實作 Web Bluetooth。
>
> 解法是 App Store 安裝免費的 **「Bluefy – Web BLE Browser」**（自帶原生 BLE 橋接），用它開啟網址。

其餘功能（繪圖、面積、匯出、拍照）在所有現代瀏覽器都正常，只是要手動輸入尺寸。

程式偵測到不支援時會直接說明**原因與做法**，並區分四種情況：
iOS 引擎限制、網址不是 HTTPS、在 LINE／FB 等 App 內建瀏覽器裡開啟、其他瀏覽器。

## 量房流程

### 1. 連測距儀

點右上「藍牙」→「搜尋並連線」→ 在清單中選測距儀。
按下測距儀量測鍵，數值就會跳進畫面下方的量測列。

**只顯示測距儀**（預設**關閉**）：預設列出全部裝置，保證每一台測距儀都找得到。
勾選後改依廣播內容過濾、清單較短 —— 但過濾比對的是**廣播封包**，
有些機種（實測 MILESEEY S2）不把名稱與服務放進廣播，開著它就整台消失。
兩台測距儀輪流用的話請保持關閉；清單空的時候畫面也會給你一鍵關掉。

連對過一次之後會**記住裝置名稱並加入篩選**（最多 8 台）——
換另一支測距儀時兩台都會出現在清單裡，不會互相排擠。
「名稱關鍵字」欄位是額外加進篩選用的，留空即可。

連上後立刻判定是不是測距儀：收到資料 → 綠色「就是這台」；沒有可訂閱的特徵值 → 紅色「幾乎確定不是」，
並附「這台不是 → 換下一台」一鍵重選。

### 2. 已內建的機種格式

| 樣板 | 封包 |
|---|---|
| `ATD/32BE@3×0.1` | `41 54 44 \| dd dd dd dd \| ck \| 23` — Kcsoft（科創）等機種。`ATD` 標頭 + 4 bytes 大端距離（0.1 mm）+ 累加檢查碼 + `#` |
| `AA/32BE@3` | `AA` 起始，第 3–6 byte 為距離（mm，大端） |
| `55/32LE@2×0.1` | `55` 起始，4 bytes 小端（0.1 mm） |
| `F32LE@0(m)` | 4 bytes 浮點（公尺） |
| `ASCII` | 文字格式，支援 `0.563m` / `3.257` / `D: 3.257 M` / `1234mm` / `123.4cm`（MILESEEY S2 屬此類） |

有宣告標頭或檢查碼的樣板，每一包都會驗證，所以電量、狀態封包不會被誤判成距離。

**設定檔會綁定到特定的特徵值。** 測距儀通常同時推播距離、電量、傾角、心跳好幾種封包，
認出距離來自哪個特徵值之後就只聽那一個 —— 否則心跳封包會被當成距離
（實測 MILESEEY S2 的心跳 `A6 09` 會被誤讀成 2470 mm）。

### 3. 未知機種的自動辨識

已知樣板都不符合時，程式會收集連續幾包資料自己推出距離欄位：

1. 找出各包之間**會變動**的位元組 —— 距離欄位一定在裡面
2. 先辨識累加檢查碼並排除（它也會跟著變）
3. 候選欄位必須**完整涵蓋所有變動位元組**
4. 排除含「固定且非零」位元組的欄位 —— 無號距離的高位必為 0
5. **數值差距要 ≥ 100 mm 且至少 3 個相異值** —— 心跳只會微幅跳動，用這點把它擋掉
6. 連線後前 12 秒不啟動猜測，先讓 ASCII 與已知樣板有機會

八種不同結構的封包（大端／小端、u16/u24/u32/float、含或不含檢查碼、欄位前後有旗標）測試全數正確。

倍率單靠封包無法斷定 —— 同一組位元組，187 mm 和 1872 mm 都是合理的室內距離。
所以辨識完會跳出視窗顯示解讀結果，請你**對照測距儀螢幕上的數字**確認。

都失敗時開「藍牙 → 學習模式」：量一段距離、輸入測距儀螢幕上的數值，做兩次不同距離即可。

### 4. 串流機種

有些測距儀（例如 MILESEEY S2）**持續串流目前讀數**，每秒重送三次，不按量測鍵也一直送。

| 情況 | 行為 |
|---|---|
| 同一個值一直送 | **只算一次** |
| 數值變了並穩定下來 | 算一次新的量測，自動套用 |
| 即時讀數 | 一直更新（**灰色**＝尚未成立，成立才轉亮藍） |
| 要重複套用同一個數值 | 按「套用」（輸入框留空即可） |

### 5. 畫圖：兩種模式

**導線量房（推薦，工具列「導線」G）**
點一下起點，之後**每按一次測距儀就自動畫一面牆並轉 90°**，繞一圈自動閉合。
右下角面板可切左轉／右轉、微調 15°、退回一面。

**自由畫牆（工具列「畫牆」W）**
點起點 → 按測距儀或輸入長度 → 自動接續下一面。`F8` 切換正交鎖定。

**量錯了？** 按 `Backspace`（或量測面板的 ↶ 鈕）：導線中退一面牆、連續畫牆中刪掉最後一段並把起點還原、
其餘情況等同一般復原。輸入框空著時按 `Backspace` 也會退。

**自動正交追蹤（`F9`，預設開啟）** — CAD 式對齊追蹤，畫面上出現橘色虛線：

- **自由追蹤**：游標靠近既有端點的水平／垂直延伸線時自動吸附；兩線同時對齊就吸到交點
- **射線追蹤**：已有起點且開著正交時，鎖在 90° 射線上並吸到射線與其他點對齊線的交會處

### 6. 牆線位置 — 量到多少就是多少

測距儀量到的是**室內淨尺寸**，不是牆中心線。所以牆體要長在你畫的那條線的**外側**：

| 設定 | 意義 |
|---|---|
| **靠下**（預設） | 牆體長在線的下方（行進方向右手邊）。**逆時針畫房間時＝牆在室外，量 3579 圖上就是 3579** |
| 靠上 | 牆體長在線的上方 |

「上下」以「由左往右畫一面牆」為基準。面板有「換到另一邊」與「整層套用」。
轉角會自動斜接，相鄰牆面完全重合、不重疊。

牆厚只有一個統一的預設值（內外牆共用）；「外牆／內牆」只影響顯示顏色與 CAD 圖層。

### 7. 一間一間量，最後拼起來

實際量房的習慣是：**每個獨立空間連同它的門各自量完，最後再把空間拖過來對接**。

在「選取」工具下**點房間內部往外拖**，整個空間會一起搬 —— 只屬於它的牆、牆上的門窗、
裡面的家具與照片、房間名稱全部跟著走。**與隔壁共用的牆不會被搬動**。

拖曳時自動吸附，優先順序：

| 吸附 | 情境 |
|---|---|
| **門對門** | 兩個空間的門要接成一個通道。兩門平行且寬度相近時，中心自動對齊 |
| **門貼牆面** | 把房間的門貼到走道的牆上 |
| **端點對齊** | 一般的牆角拼接 |

畫面上會用綠色圓圈與連線標出即將對齊的位置。

放開後，**疊在一起的牆會自動合併成一面**，上面的門窗一併改掛過去 ——
否則兩間房中間會留下兩道重合的牆，房間偵測與面積都會出錯。

### 8. 門窗、柱體

選「門／窗／開口」工具後點在牆上即可放置，牆體會自動開洞。
右側面板可調寬高、窗台高、開向、距牆端距離。

### 9. 家具與構件（工具列「家具」F）

右側面板依 客廳／臥室／廚房／衛浴／收納／建築 分類，共 36 種構件。
點選後在圖面點一下即放置 —— **靠近牆會自動轉正並貼齊牆面**（所有符號的背面統一朝 +y）。
選取後可拖曳移動、拉上方圓點旋轉，或在面板改寬／深／高。

### 10. 現場拍照標註（工具列「拍照」P）

先在平面圖上點「你站的位置」，接著開相機拍照。照片存進來後：

- 點照片上的任一位置 → **按測距儀，量到的距離就直接標在那個點上**
- 平面圖上會出現編號的相機標記與視角扇形，DXF／SVG 也會帶到
- 「下載標註後照片」把標註燒進 JPEG，可直接傳給工班

照片存在瀏覽器本機（獨立的 IndexedDB store），存檔前自動縮到最長邊 2000px。

### 11. 房間與面積

牆體圍成封閉區域時**自動偵測為房間**，即時算出淨面積（已扣牆厚）、坪數、周長。
用「房間」工具點進去命名。房間名稱綁在一個座標點上，之後改牆也不會跑掉。

選取房間後可以**整個區域刪除** —— 會列出將刪掉幾面牆、幾樘門窗，並讓你決定要不要一併刪除
區域內的家具、照片與註記。刪除的是「這個房間用到、而其他房間沒用到」的部分，
所以與隔壁共用的牆會裁短保留，不會拆掉一間連旁邊那間也垮掉。

### 12. 風水評測（頂列「風水」）

民俗參考功能，資料表與演算法**對齊 `C:\風水羅盤` 專案**：

- **二十四山**：子居正北 0°，順時針每山 15°，含正五行、元龍、兼向判定（偏離山心 >3°）
- **八宅遊年**：以坐山所屬卦定宅卦，八方位配九星，附九星名與吉凶等級
- **文昌位**：宅卦洛書數入中順飛，四綠所落之宮，另附流年文昌
- **明財位**：客廳中離大門最遠的斜對角
- **命卦**：由屋主出生年與性別推東四命／西四命

坐向由「指定為大門的那扇門」自動推算。正北預設為圖面上方，可在面板校正。

> 這是民俗參考，不是工程或科學結論。

### 13. 出圖

| 格式 | 維度 | 用途 |
|---|---|---|
| **DXF**（本層） | 2D | AutoCAD。牆體是**封閉聚合線**（不是散線），轉角已斜接，可直接偏移、填充、查面積。分圖層（WALL / WALL-EXT / WALL-CENTER / DOOR / WINDOW / DIM / ROOM / AREA / FURNITURE / PHOTO） |
| **DAE — 純牆體** | 3D | **給 SketchUp 續作用**。只有牆，轉角斜接不重疊，門窗只留孔洞、不含門片與玻璃 |
| **DAE — 完整場景** | 3D | 牆 + 門窗玻璃 + 家具 + 樓板，分材質 |
| **DAE（全案）** | 3D | 各樓層依樓高堆疊成一份模型 |
| **SVG** | 2D | 列印、Illustrator、Figma |
| **PNG** | 2D | 傳 LINE 給業主 |
| **CSV** | — | 面積 / 牆面 / 天花 / 踢腳工程量，Excel 直接開 |
| **JSON** | — | 完整專案備份 |
| **列印** | 2D | A3 橫式排版，可另存 PDF |

**DAE 技術細節**：COLLADA 1.4.1、`Z_UP`、單位公尺。房間輪廓可能是 L 形等凹多邊形，樓板以耳切法三角化。
3D 預覽與 DAE 匯出使用**同一份幾何**（`solid.js`），畫面看到什麼就匯出什麼。

## 資料儲存

專案存在瀏覽器的 **IndexedDB**，離線完全可用，不上傳任何資料。
清除瀏覽器資料會一併清掉，請定期用「匯出 → 專案備份 JSON」保存。

**雲端同步**（需要 `server.mjs`）：同步的目的地就是跑這支程式的機器。
提供上傳／取回、分享連結（唯讀頁面給業主看平面圖、面積表與現場照片）。
公開部署時務必設 `SYNC_TOKEN` 環境變數。

```
  model.js              資料模型 + undo/redo
  store.js              IndexedDB 儲存（專案 + 照片 Blob）
  ble.js                Web Bluetooth 連線、封包解析、自動辨識、學習模式
  catalog.js            家具／構件圖庫（36 種）
  photos.js             現場拍照、照片標註、標註燒錄
  fengshui.js           八宅 · 二十四山
  sync.js / share.js    雲端同步 / 唯讀分享頁
  export-dxf.js         AutoCAD DXF 輸出
  export-svg.js         向量平面圖輸出
  export-dae.js         COLLADA 3D 模型輸出
  report.js             面積 / 工程量報表
  view3d.js             等角投影 3D 簡圖
data/                   自架雲端的資料（伺服器產生）
```

單位一律以 **mm** 存於模型內部，顯示單位（mm / cm / m）可在設定切換。
模型座標系 Y 向上（與 CAD 一致），畫布繪製時才翻轉。

## 已知限制

- 目前只支援直牆，弧形牆尚未實作。
- 3D 為體塊簡圖，不含家具模型與材質彩現。
- 靜態託管（Cloudflare Pages 等）沒有後端，雲端同步與分享連結需自行跑 `server.mjs`。
- 測距儀的「遠端觸發測量」指令因各機種不同，預設未啟用（藍牙面板可自行送十六進位指令）。
